# マニュアルのダウンロード

このマニュアルは、**Webで読む**ほかに、端末やEPUBリーダーで読める形でも配布しています。
内容はすべて同じで、画面写真も収録済みです。

## 端末で読む（XTC / XTCH）

日本語XTC GUI Studio 自身で変換したファイルです。X3・X4へそのまま転送して読めます。

| ファイル | 端末 | 形式 | サイズ |
|---|---|---|---|
| [nihongo-xtc-manual_v3.1.2.9_x4.xtch](nihongo-xtc-manual_v3.1.2.9_x4.xtch) | Xteink X4（480×800） | XTCH（4階調） | 約13.0 MB |
| [nihongo-xtc-manual_v3.1.2.9_x4.xtc](nihongo-xtc-manual_v3.1.2.9_x4.xtc) | Xteink X4（480×800） | XTC（2階調） | 約6.5 MB |
| [nihongo-xtc-manual_v3.1.2.9_x3.xtch](nihongo-xtc-manual_v3.1.2.9_x3.xtch) | Xteink X3（528×792） | XTCH（4階調） | 約13.6 MB |
| [nihongo-xtc-manual_v3.1.2.9_x3.xtc](nihongo-xtc-manual_v3.1.2.9_x3.xtc) | Xteink X3（528×792） | XTC（2階調） | 約6.8 MB |

**XTCHをおすすめします。** 画面写真が多いため、4階調のほうが細部がつぶれにくくなります。

- 全21章・約150ページ、目次（章情報）と表紙・サムネイル入り
- **画面写真は縦向きで統一**しています。端末の画面幅に合わせて縮小されるため、
  UIの細かい文字までは読めません。**細部を確認したいときはWeb版またはEPUB版**をご覧ください
  （回転して収録すれば読めるようになりますが、大半の図が横向きになり、
  読み進めるたびに端末を持ち替えることになるため、通読しやすさを優先しています）

## EPUBリーダーで読む

| ファイル | 形式 | サイズ |
|---|---|---|
| [nihongo-xtc-manual_v3.1.2.9.epub](nihongo-xtc-manual_v3.1.2.9.epub) | EPUB 3 | 約2.8 MB |

- 全20文書・画面写真38枚を**原寸で収録**しています。リーダーの拡大機能で細部まで確認できます
- 目次（nav）付きなので、章から章へ飛べます
- このEPUBは日本語XTC GUI Studio でXTC化することもできます（実際に変換できることを確認済み）

## ダウンロード方法

GitHubのファイル表示ページを開き、右上の **［Download raw file］**（下向き矢印のアイコン）を
押すと保存できます。ファイル名をクリックしただけでは、ブラウザ上でプレビューされるだけの
場合があります。

## Web版

最新版は常に [Web版](https://miya-bee.github.io/nihongo--xtc-gui-studio-manual/) にあります。
画面写真をクリックすると原寸で拡大表示できるため、細部を確認したいときはこちらが確実です。
