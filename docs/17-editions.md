# 17. 版（エディション）の違い

日本語XTC GUI Studio には3つの版があります。**変換品質・組版機能そのものはどの版でも同じ**で、
違うのは下表の項目だけです。

| | Lite版 | Full版 | Trial版 |
|---|---|---|---|
| 変換（TXT/MD/EPUB/PDF/画像/アーカイブ） | ○ | ○ | ○（ページ数上限あり） |
| プレビュー・組版設定・プリセット | ○ | ○ | ○ |
| 書籍情報・表紙・目次・サムネイル | ○ | ○ | ○ |
| XTCツール（編集・検証・画像変換） | ○ | ○ | 一部制限 |
| フォルダ一括変換 | ○ | ○ | ○（ページ数上限あり） |
| EPUB分割・切出し | ○ | ○ | ○ |
| 青空文庫ダウンロード | ○ | ○ | ○（ページ数上限あり） |
| 記事URL（Web記事） | ○ | ○ | ○（ページ数上限あり） |
| X3/X4への送信 | ○ | ○ | ○ |
| **小説URL：AozoraEpub3直接** | ○ | ○ | ○ |
| **小説URL：narou.rs経由** | **×** | ○ | ○ |
| **登録作品（ライブラリ管理）** | **×** | ○ | ○ |
| 出力ページ数の上限 | なし | なし | **あり（下記）** |

## Lite版の制限

Lite版は Full版の機能をほぼそのまま備えていますが、**小説URL（Web小説のEPUB化）の取得方式が
「AozoraEpub3直接」に限定**されます。narou.rs を使う方式は選択できません（UI上でグレー表示になります）。

あわせて、作品を一覧で管理する **登録作品（ライブラリ）機能** も利用できません。
アプリ内には次のように表示されます。

> v3.1 Liteでは、登録作品機能を利用できません。一覧・検索・再読込、詳細表示、EPUB更新、
> Studio送信、XTC状態の記録、登録解除は、v3.2系で有効化予定です。

Lite版でもWeb小説のEPUB化そのものは可能です。URLを都度入力して1作品ずつ変換する使い方になります。

## Trial版の制限

Trial版は、**出力されるページ数に上限**があります。変換元の種類ごとに異なります。

| 変換元 | 出力ページ数の上限 |
|---|---|
| ファイル入力（EPUB / TXT / Markdown / PDF / ZIP / CBZ、フォルダ一括変換を含む） | 5ページ |
| 青空文庫ダウンロード | 10ページ |
| 記事URL（Webページ記事） | 3ページ |

また、ウィンドウのタイトルバーに「Trial版」と表示されます。

## お使いの版を確認するには

ウィンドウ最上段のタイトルバーに、アプリ名とバージョンが表示されます。

- `... v3.1.x Lite` → Lite版
- `... v3.2.x` / `v3.3.x` → Full版
- 末尾に `Trial版` → Trial版
