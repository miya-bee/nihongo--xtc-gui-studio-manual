# 17. 版（エディション）の違い

日本語XTC GUI Studio には **Full版** と **Trial版** があります。
**変換品質・組版機能そのものはどちらの版でも同じ**で、違うのは下表の項目だけです。
このマニュアルは **v5.0.0f Full版** を基準に書いています。表の【v3.3から】は v4.0.0 で入った機能です（v3.3 は v4.0.0 の開発版の名前です）。

| | Full版 | Trial版 |
|---|---|---|
| 変換（TXT/MD/EPUB/PDF/画像/アーカイブ） | ○ | ○（ページ数上限あり） |
| プレビュー・組版設定・プリセット | ○ | ○ |
| 書籍情報・表紙・目次・サムネイル | ○ | ○ |
| 縦長分割・横長分割・白紙ページ除外 | ○ | ○（ページ数上限あり） |
| XTCツール（編集・検証・画像変換） | ○ | 一部制限 |
| フォルダ一括変換 | ○ | ○（ページ数上限あり） |
| EPUB分割・切出し | ○ | ○ |
| 青空文庫ダウンロード | ○ | ○（ページ数上限あり） |
| 記事URL（Web記事） | ○ | ○（ページ数上限あり） |
| X3/X4への送信 | ○ | ○ |
| 小説URL（AozoraEpub3直接／narou.rs経由）・登録作品 | ○ | ○ |
| 【v3.3から】連載の更新管理（続きだけのXTC） | ○ | ○（変換はページ数上限あり） |
| 出力形式 XTCH v2（SROS専用） | ○ | ○ |
| LZ4圧縮（SROS専用） | ○ | × |
| 【v4.0.6から】LZ4一括圧縮（歯車メニュー。SROS専用） | ○ | × |
| 【v5.0.0dから】XTCツールの LZ4解凍 | ○ | ○ |
| 【v5.0.0eから】出力ファイル名の形式（`[{author}]{title}` など） | ○ | ○ |
| 【v5.0.0から】(β版) ebook2xtc の案内（歯車メニュー） | ○（Windows版のみ） | × |
| マンガ用の機種・プリセット（SROSの Comic Reader 用） | ○ | ○ |
| バッチ実行（コマンドライン） | ○ | ○（ページ数上限あり） |
| 出力ページ数の上限 | なし | **あり（下記）** |

## Trial版の制限

Trial版は、**出力されるページ数に上限**があります。変換元の種類ごとに異なります。

| 変換元 | 出力ページ数の上限 |
|---|---|
| ファイル入力（EPUB / TXT / Markdown / PDF / ZIP / CBZ、フォルダ一括変換を含む） | 5ページ |
| 青空文庫ダウンロード | 10ページ |
| 記事URL（Webページ記事） | 3ページ |

また、ウィンドウのタイトルバーに「Trial版」と表示されます。

## お使いの版を確認するには

ウィンドウ最上段のタイトルバーに、アプリ名とバージョン（例: `日本語XTC GUI Studio v5.0.0f`）が表示されます。
Trial版では末尾に「Trial版」と付きます。
