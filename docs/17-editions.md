# 17. 版（エディション）の違い

日本語XTC GUI Studio には **Full版** と **Trial版** があります。
**変換品質・組版機能そのものはどちらの版でも同じ**で、違うのは下表の項目だけです。
このマニュアルは **v3.2 Full版** を基準に書いています。

| | Full版 | Trial版 |
|---|---|---|
| 変換（TXT/MD/EPUB/PDF/画像/アーカイブ） | ○ | ○（ページ数上限あり） |
| プレビュー・組版設定・プリセット | ○ | ○ |
| 書籍情報・表紙・目次・サムネイル | ○ | ○ |
| 縦長分割・白紙ページ除外 | ○ | ○（ページ数上限あり） |
| XTCツール（編集・検証・画像変換） | ○ | 一部制限 |
| フォルダ一括変換 | ○ | ○（ページ数上限あり） |
| EPUB分割・切出し | ○ | ○ |
| 青空文庫ダウンロード | ○ | ○（ページ数上限あり） |
| 記事URL（Web記事） | ○ | ○（ページ数上限あり） |
| X3/X4への送信 | ○ | ○ |
| 小説URL（AozoraEpub3直接／narou.rs経由）・登録作品 | ○ | ○ |
| 出力ページ数の上限 | なし | **あり（下記）** |

## Trial版の制限

Trial版は、**出力されるページ数に上限**があります。変換元の種類ごとに異なります。

| 変換元 | 出力ページ数の上限 |
|---|---|
| ファイル入力（EPUB / TXT / Markdown / PDF / ZIP / CBZ、フォルダ一括変換を含む） | 5ページ |
| 青空文庫ダウンロード | 10ページ |
| 記事URL（Webページ記事） | 3ページ |

また、ウィンドウのタイトルバーに「Trial版」と表示されます。

## お使いの版を確認するには

ウィンドウ最上段のタイトルバーに、アプリ名とバージョン（例: `日本語XTC GUI Studio 3.2.0`）が表示されます。
Trial版では末尾に「Trial版」と付きます。
