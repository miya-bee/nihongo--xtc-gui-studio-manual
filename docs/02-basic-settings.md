# 2. 基本設定ブロック

中央の設定エリアは、上から「基本設定」「組版」「位置補正」の3ブロックに分かれています。
この章では一番上の **基本設定** ブロックを説明します。

![基本設定ブロック](../images/section-basic.png)

出力するファイルの形式や、原稿全体の扱いを決める項目が並びます。

## 機種・出力形式

**機種**を選ぶと解像度が自動設定されます。手動で幅・高さを指定したいときは「Custom」を選びます。

出力形式は3通りです。

| 選択肢 | 内容 |
|---|---|
| **XTC** | 2階調（白黒）のXTCファイルを1つ保存 |
| **XTCH** | 4階調（白黒4段階）のXTCHファイルを1つ保存 |
| **XTC・XTCH** | 同じ原稿から両方を保存。書籍情報・目次・表紙・サムネイル・ページ構成は両方で揃う |

「XTC・XTCH」を選んでいるときのプレビューは、階調が少ないXTC側を表示します。
使い分けの目安は、**通常の白黒表示ならXTC、階調を残したい画像寄りの用途ではXTCH**です。

![出力形式のヘルプ](../images/help-popup-output-format.png)

## 文字太らせ

二値化前に細い線を太らせます。「なし」または1〜6を選べます。1が最も弱く、6が最も強い設定です。
旧バージョンの「弱」は2、「強」は6に相当します。白黒反転時は白文字が太ります。

> 挿絵や写真も一様に太る（暗部が広がる）点に注意してください。全入力ソースに適用されます。

## 組方向・画面の向き

**組方向**は縦書きが既定です。横書きを選ぶと本文が左上から右・下方向へ流れます。
横書きでは使わない位置補正ブロックを自動的に隠し、縦書きへ戻すと以前の設定値を保持したまま再表示します。

**画面の向き**は横書き専用の設定で、端末を倒す向きを選びます。「右に倒す」は端末の上端が右側へ、
「左に倒す」は端末の上端が左側へ来る持ち方です。「横」を選ぶとページを横長で組版し、回転して出力します。
横向きでは、余白の上下左右は端末を倒して読む状態での上下左右を指し、本文と一緒に回転します。

> PDF・画像・画像アーカイブは組版を行わないため、組方向は選択中無効になります。

## 奥付

チェックすると、最終ページの後ろに変換日時・アプリバージョン・フォント・文字サイズ・余白などの
使用設定を横書きで印字した1ページを追加します。

「この設定が良かったから同じ設定で変換したい」というときに、出力ファイル自体から設定を確認できます。
既定値から変更した組版オプションも一覧で印字します。

## ページ送り方向

PDF・画像・画像アーカイブ、およびそれらを含むフォルダ一括変換で使う設定です。

> Studioは**PDFや画像の縦書き・横書き・漫画判定を行いません**。
> 縦書き書籍や一般的な日本の漫画は「右→左」、横書き文書などは「左→右」を選んでください。

TXT/EPUB/Markdownは組方向から自動的に決まります。この指定は、進捗バーの進行方向が
「ページ送り方向に合わせる」のときにも使われます。

## ファイル分割

一部のカスタムOS環境で100MB前後のXTC/XTCHを開けない場合に使います。
チェックすると、指定MB（上限MB）を超える出力をページ単位で複数のXTC/XTCHへ分割します。
ファイル名には `p001-p120` のようにページ範囲を付けます。

分割するときは、**できるだけ章の境目で区切り**、分けたそれぞれのファイルの目次と章のページ番号を作り直します。

> **XTC/XTCHは1ファイル最大65,535ページです。** これを超える場合は、
> ファイル分割がOFFでも自動的に分割します。このときはページ数だけを理由に分けるので、
> 選んでいない容量上限（既定の95MB）は使いません。

## 出力ページ上限

指定したページ数で出力を打ち切ります。「無制限」なら全ページを出力します。
記事末尾の関連リンクや広告など、変換したくない終わりの数ページを落とす用途に使います。
プレビューでページ番号を確認してから指定してください。

> この値は**プリセットには保存されません**（読み込んだだけで出力が短くなるのを防ぐため）。

## Markdownレイアウト（横書き）

横書きでMarkdownファイルを選んだときだけ設定欄が表示されます。
縦書きのときは「Markdownレイアウトの7設定は横書き専用です」という案内が代わりに出ます。

| 項目 | 選択肢 | 内容 |
|---|---|---|
| **章改ページ** | なし／H1／H1〜H2／H1〜H3 | 指定した見出しの直前で改ページする |
| **水平線** | 空行／罫線／改ページ | `---` をどう扱うか |
| **表** | テキスト／罫線表 | パイプ表を文字のまま流すか、列をそろえた表として描くか |
| **表罫線** | 横罫のみ／全罫線 | 罫線表の線の引き方。「横罫のみ」は行の区切り線だけ、「全罫線」は縦線も含めた格子 |
| **見出しサイズ階層** | チェック | H1/H2/H3を本文より大きくする |
| **H1サイズ（%）** | 100〜250% | 見出しサイズ階層のときのH1の大きさ。H2/H3はそこから段階的に小さくなる。170%が従来どおり |
| **リストのネスト字下げ** | チェック | リストの先頭空白による階層（字下げ）を残す |
