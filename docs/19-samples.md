# 19. 変換後サンプル集

「設定を変えると出力がどう変わるのか」を、実際の出力ページで確認できるページです。
ここに載せている画像は**すべて実際に変換した結果**で、作図やモックアップではありません。

各サンプルの下に、その見た目を作っている設定へのリンクを置いています。

---

## TXT（縦書き・ルビあり）

![TXTを縦書き変換した出力](../images/sample-output-txt-vertical.png)

いちばん基本の出力です。青空文庫記法のルビ `《…》` がそのまま親文字の右に振られます。

この見た目を決めている設定:

| 見えているもの | 設定場所 |
|---|---|
| 縦書きで右から左へ流れる本文 | [組方向](02-basic-settings.md#組方向画面の向き) |
| 本文の大きさ・行間・余白 | [フォント・サイズ・余白](03-typesetting.md#フォントサイズ余白) |
| ルビ（吾輩→わがはい など）の大きさと位置 | [ルビ補正](03-typesetting.md#フォントサイズ余白) |
| 行末の記号の詰まり方 | [禁則処理](03-typesetting.md#段落禁則) |
| 右下のページ番号 | [ページ表示](03-typesetting.md#ページ表示) |
| 下部の黒い横棒（読書位置） | [進捗バー](03-typesetting.md#進捗バー) |

---

## Markdown（横書き・見出しあり）

![Markdownを横書き変換した出力](../images/sample-output-markdown-horizontal.png)

Markdownを横書きで変換した例です。見出しが本文より大きく組まれ、箇条書きと表が展開されています。

この見た目を決めている設定:

| 見えているもの | 設定場所 |
|---|---|
| 左上から右・下へ流れる本文 | [組方向](02-basic-settings.md#組方向画面の向き) |
| 見出しが本文より大きい | [Markdown専用設定](03-typesetting.md#markdown専用設定横書き) |
| 箇条書きの字下げ | [ネスト字下げ](03-typesetting.md#markdown専用設定横書き) |
| 表の描画 | [表罫線](03-typesetting.md#markdown専用設定横書き) |
| 見出しが目次に入る | [目次タブ](08-book-metadata.md#8-3-目次タブ) |

---

## 画像アーカイブ（ZIP / CBZ）

![画像アーカイブを変換した出力](../images/sample-output-image-archive.png)

漫画などの画像アーカイブは、**組版を行わず**各画像を1ページとして収めます。

この見た目を決めている設定:

| 見えているもの | 設定場所 |
|---|---|
| ページの送り方向（右→左 / 左→右） | [ページ送り方向](02-basic-settings.md#ページ送り方向) |
| 白黒への変換のしかた | [ディザリング・しきい値](03-typesetting.md#画像処理) |
| 線の太さ | [文字太らせ](02-basic-settings.md#文字太らせ) |
| 紙の余白を削って本文を大きく | [余白トリミング](03-typesetting.md#画像処理) |
| 横長ページだけ回転 | [横長回転](03-typesetting.md#画像処理) |

> 画像アーカイブでは、Studioは縦書き・横書き・漫画かどうかの判定を行いません。
> ページ送り方向は手動で指定してください。

---

## 画面上での確認

出力ファイルを開かなくても、右ペインのプレビューで同じ見た目を確認できます。
変換前に設定を詰めるときは、[6. プレビュー（右ペイン）](06-preview.md)を活用してください。

実際の端末での大きさを確かめたいときは、プレビューの **［実寸］** を使います。
