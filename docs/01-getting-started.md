# 1. はじめに・画面の見方

## 基本の流れ

アプリが案内している基本の流れは次の5ステップです（ツールバーの「?」ボタン［使い方の流れ］でも確認できます）。

1. ファイルを開く
2. プリセットを選ぶ
3. 必要なら微調整
4. 変換実行
5. 右ペインで確認

![メイン画面](../images/main-window.png)

画面は大きく3つに分かれています。

| 部分 | 役割 |
|---|---|
| 左：プリセットパネル | 保存済みの設定（プリセット）を選ぶ・保存する |
| 中央：組版設定 | 出力形式・フォント・余白・禁則処理などを1画面で調整する |
| 右：プレビュー | 変換後の見た目をページ単位で確認する |

上部のツールバーには、ファイルの取り込み口が並んでいます。

- **ファイルを開く** … EPUB / TXT / Markdown / PDF / 画像アーカイブなどをローカルから選ぶ。
  上部のパス欄へファイルをドラッグ＆ドロップしても開けます
- **読み直し** … いま開いているファイルを読み直して、プレビューを作り直す（F5キーでも同じ。
  [後述](#元ファイルを直しながら確認する)）
- **ClipBoard** … クリップボードのテキストまたはHTMLを変換対象にする。
  テキストはそのまま、HTMLは記事URLと同じ画面（[9章](09-article-url.md)）で取り込みます
- **青空文庫** … 作品を検索してダウンロード（[10章](10-aozora.md)）
- **小説URL** … Web小説をnarou.rsまたはAozoraEpub3でEPUBにする（[11章](11-narou.md)）
- **記事URL** … Webページの記事本文を取り込む（[9章](09-article-url.md)）
- **一括変換** … フォルダ単位でまとめて変換する（[12章](12-folder-batch.md)）

## 左パネルを閉じる

画面右上の三本線ボタン（≡）は、メニューではなく**左のプリセットパネルの開閉トグル**です。
中央の組版設定を広く使いたいときに押します。もう一度押すと元に戻ります。

![左パネルを閉じた状態](../images/main-window-panel-collapsed.png)

## ヘルプの読み方

各設定項目の右にある `?` ボタンを押すと、その項目だけの説明がポップアップで表示されます。
迷ったときはまずここを確認してください。

![ヘルプポップアップの例（出力形式）](../images/help-popup-output-format.png)

## 歯車メニュー

画面右上の歯車（⚙）ボタンには、表示の設定と、メイン画面以外の道具がまとまっています。

| 項目 | 内容 |
|---|---|
| 白基調／ダーク | 画面の配色 |
| ヘルプの文字サイズ | `?` で開く説明の文字の大きさ |
| 書籍情報… | 書名・表紙・目次・サムネイルの設定（[8章](08-book-metadata.md)） |
| XTCツール… | 変換済みファイルの確認と編集（[14章](14-xtc-tools.md)） |
| EPUB分割… ／ EPUB切出し… | 大きなEPUBを分ける（[15章](15-epub-split.md)） |
| 記事データを開く… | 保存済みの記事データ（.xtca）を開き、変換対象にする |
| X3/X4へ送信… | 登録済みの端末へEPUB/XTC/XTCHを送る（[16章](16-device-transfer.md)） |
| デフォルト保存先… | 単体変換の保存先。未指定ならソースファイルと同じフォルダ |
| 三本線ボタンを表示 | 左パネルの開閉ボタン（≡）の表示・非表示 |
| ページ送りキー反転 | ページ送り用の矢印キーの前進・後退を入れ替える。縦書き作品をキーボードで直感的にめくりたいとき |
| 元ファイルの変更を知らせる | [後述](#元ファイルを直しながら確認する)。初期設定はオフ |
| 同名出力 | 保存先に同じ名前のファイルがあるときの動作（[5章](05-convert-and-check.md#5-4-変換結果タブ)） |
| サムネイル出力サイズ… | 埋め込みサムネイルと `cover.xtg` の大きさ。既定は180×270px |
| PNG保存 | 表示中のプレビュー1ページを枠付きPNGとして保存する |
| サムネイル書出 | 表示中のページから `cover.xtg` を書き出す。SDカードの `/XTCache/xtc/<ファイル名>/cover.xtg` へコピーすると、端末のトップメニューにサムネイルが出ます（Xteink実機の非公式な挙動） |

## 元ファイルを直しながら確認する

TXTやMarkdownをエディタで書きながら、端末での見え方を確かめたいときの機能です。

- **［読み直し］（F5）** … エディタで元ファイルを保存したあと、ファイルを選び直さずにプレビューへ反映します。
  「書籍情報を開きますか？」の確認は出ず、書籍情報・変換設定・表示中のページ位置はそのまま残ります
- **元ファイルの変更を知らせる**（歯車メニュー、初期設定はオフ） … オンにすると、
  元ファイルがプレビューより新しくなったとき、上部に
  「元ファイルが更新されています［読み直し］［×］」と色付きの1行を表示します。
  数秒おきに元ファイルの保存日時を見ているので、**エディタを並べて置き、Studioを前面にしたまま保存した場合にも**
  数秒で出ます（Studioへ戻るのを待つ必要はありません）

お知らせについて、覚えておくと迷わない点です。

- ［読み直し］を押すと、お知らせは消えます。［×］で閉じたときは、**同じ内容の変更では再び出ません**。
  さらに保存し直して元ファイルが新しくなったときに、また出ます
- 変換の実行中は出しません。ファイルが消えたときや、別のファイルに切り替えたときも出ません
- ダイアログではないので、作業は止まりません。確認するのは保存日時だけで、ファイルの中身は読みません

### XTC/XTCHを開いているとき

［XTCファイルを開く］などでXTC/XTCHを表示している間の［読み直し］（F5）は、**表示しているそのXTC/XTCHファイルを、ディスクから読み直します**。再変換や圧縮で同じ名前のファイルが入れ替わったあとに、開き直さず確認できます。見ていたページの位置は保ちます（ファイルのページ数が減ったときは、最後のページに収まります）。

元のTXT・Markdown・PDFなどの**編集内容を読み直すものではありません**。XTC/XTCHの表示中は、元ファイルのプレビューを作り直せないので、元ファイルを直したときは、［ファイルを開く］で元ファイルを選び直してください。

## 新しい版へ乗り換えるとき（設定引き継ぎツール）

ポータブル版はインストールせずフォルダごと置いて使うため、
新しい版を展開すると設定は初期状態から始まります。
前の版で作った設定を持ち込むための小さなツールが同梱されています。

新しい版のフォルダにある **`START_SETTINGS_MIGRATE.bat`** をダブルクリックしてください
（本体とは別の軽量な引き継ぎツール `TategakiXTC_SettingsMigrate.exe` が起動します）。
あとは**前の版のフォルダを選ぶだけ**です。

引き継がれるもの:

- 組版・出力の設定そのもの（フォント・文字サイズ・余白・位置補正・画像処理など、画面で選んでいた値）
- プリセット、表紙プリセット
- 書籍情報（ファイルごとに保存した書名・表紙などの設定）
- フォルダ一括変換の設定
- 追加したフォント
- 小説URL（URL→EPUB）の取得履歴、narou.rs の管理データ、差分台帳、EPUBキャッシュ
- ログ

引き継がれないもの（新しい環境で決め直すもの）:

- 保存先フォルダ
- ウィンドウの大きさ・位置、ペインの幅
- 表示中のページや倍率、最近使ったファイルなど、その環境固有の項目

> 引き継ぎは**新しい版のフォルダから**実行します。前の版のフォルダで動かすものではありません。
> コピーの前に空き容量を確認し、小説取得データの中に書かれた古いフォルダの場所も
> 新しい版に合わせて書き換えます。

> 前の版のフォルダは消さずに残しておけます。別フォルダに展開した新旧の版は併存でき、
> 新しい版で問題があれば前の版に戻せます。
