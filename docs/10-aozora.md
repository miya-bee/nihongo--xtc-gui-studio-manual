# 10. 青空文庫の作品を取り込む

上部ツールバーの「青空文庫」から、青空文庫の公開中作品を検索し、HTML版またはテキスト版を
ダウンロードして変換対象にできます。

![青空文庫検索ダイアログ](../images/aozora-search.png)

## 使い方

1. 「作品名・作者名で検索」欄にキーワードを入れて検索する（初回はカタログの読み込みに少し時間がかかります）
2. 一覧から作品を選ぶと、下の「選択作品の詳細」に情報が表示されます
3. **取得形式**（HTML優先など）と**HTMLの改行**（段落ごとに空行、など）を必要に応じて調整します
4. 「変換可能な作品のみ」にチェックすると、対応していない形式の作品を一覧から除外できます
5. 「ダウンロードして変換対象にする」を押すと、メイン画面の変換対象として設定されます

「図書カードを開く」で、選択中の作品の青空文庫サイト上のページを確認できます。

## 補足

- ルビ・傍点・字下げなど、青空文庫記法のほとんどはそのまま反映されます（下の一覧を参照）
- ダウンロード結果はキャッシュされるため、同じ作品を何度も選び直しても再ダウンロードは発生しません
- 章立て（目次）は、青空文庫の見出し記法（大見出し・中見出し・小見出しなど）から自動的に検出されます

## 対応している青空文庫の注記

青空文庫からダウンロードした作品だけでなく、青空文庫記法で書いたTXTにも同じように効きます。
v3.2 で次の注記に対応しました。

| 注記 | 内容 |
|---|---|
| **罫囲み** | `［＃ここから罫囲み］`〜`［＃ここで罫囲み終わり］`、`［＃罫囲み］`〜`［＃罫囲み終わり］`、`［＃「…」は罫囲み］`。縦書きは列ごと、横書きは行ごとに四方を囲みます。枠の中の字下げやルビも枠に収め、ページをまたぐ枠は、続きの側の辺を開けて継続を表します |
| **小書き・上付き・下付き** | 小書き、上付き小文字・下付き小文字、行右小書き・行左小書き。縦書きの行右・行左小書きは本文の70%、横書きの上付き・下付きは75%で描きます |
| **訓点（返り点・送り仮名）** | 漢文の返り点と送り仮名。左ルビ・送り仮名・返り点が同じ字に付いても、どれも消えません |
| **「左に」を伴う指定** | `［＃左に傍点］`、`［＃ここから左に傍線］` など |
| **くの字点** | 青空文庫が代用表記で書いている `／＼`・`／″＼` を、本来の文字 〳〵・〴〵 に直して描きます |
| **ページ内の位置** | 「ページの左右中央」「地付き」「地から〇字上げ」。TXT・Markdown・EPUBでも解釈します |
| **注記形式のルビ** | `［＃「X」に「Y」のルビ］`。「ママ」などの注記も同じ位置へ小さく添えます |
| **改頁** | 「改ページ」と同じ改ページ指示として扱います |
| **太字** | 既定は疑似太字。ゴシック体で描く設定もあります（→ [3章](03-typesetting.md#青空文庫の太字をゴシック体にする)） |

**横書きで、ルビ付きの文字を罫囲みにした行が続くとき**は、上下の枠の間に白い隙間を2px空け、罫線が本文やルビに重ならないようにします。行送りが詰まっていて足りないときは、下の段落を足りない分だけ下げて描くため、ページの区切りが少し変わることがあります。罫囲みを使わない原稿と、縦書きの罫囲みは変わりません。ルビが枠より長いときは、ルビが枠の外へはみ出します。

**横書きで罫囲みがページをまたぐとき**は、続くほうのページの下辺と、続きのページの上辺を開けて、「まだ続きがある」と分かるようにします（間のページは上下とも開きます。左右の辺は残ります）。1ページに収まる囲みは、四辺を閉じます。**文字太らせを重くしたとき**（5〜6）も、上下の枠の間の白と、罫線の内側の余白が保たれるように間隔を取ります。

傍点の既定（種類を書かない `［＃「X」に傍点］`）は黒ゴマです。
傍線の太さは本文の大きさに合わせ、二重傍線の間隔も線の太さに応じて広げます。

> **まだ対応していない注記**: **字詰め**の指定（`［＃ここから○字詰め］` など）は、いまのところ反映されません。
> 対象の文字列が本文と一致せず注記を当てはめられないときは、注記を黙って捨てずに
> 変換ログへ入力警告として記録します。
