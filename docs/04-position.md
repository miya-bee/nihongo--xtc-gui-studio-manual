# 4. 位置補正ブロック

縦書きでは、記号や英数字の見え方がフォントによって微妙に変わります。
このブロックは、そうした**文字種ごとの位置と間隔の微調整**をまとめたものです。

> **b版（タブ表示）では** この章の項目はすべて「位置補正」タブにあります（中身も並び順も同じです）。

![位置補正ブロック](../images/section-position.png)

> このブロックは**縦書き専用**です。組方向を「横書き」にすると自動的に隠れ、
> 縦書きへ戻すと以前の設定値を保持したまま再表示されます。

## 文字種ごとの位置

次の項目は、いずれも「標準」からの位置ずらしを指定します。
フォントを変えたときに文字が上下・左右へ寄って見える場合に調整します。

選択肢は **上補正6〜1・標準・下補正1〜6 の13段階**です。数値が大きいほど補正が強くなります
（2は従来の「弱」、4は従来の「強」と同じです）。

| 項目 | 対象 |
|---|---|
| 句読点 | 、 。（**ぶら下がりになったものだけ**） |
| 漢数字 一 | 文中すべての漢数字「一」 |
| 全角英字 | Ａ〜Ｚ／ａ〜ｚ（全角数字・半角英字・ルビ内の英字は対象外） |
| 半角英字 | A〜Z／a〜z（半角数字・数値記号・全角英字・ルビ内の英字は対象外） |
| 半角数字/記号 | 半角数字、数値記号（/ . , : ; + - = % など）、縦中横の半角数字（全角数字・ルビ内の数字は対象外） |
| 下鍵括弧 | 閉じ括弧 」 ﹂ 】 ］ ） ｠ ｝ 〗 と、二重閉じ鍵括弧 』 ﹄ |
| 縦中横記号 | 縦中横で描く記号ペア（！？ ？？ ！！ ？！ !? ?? !! ?!）。数字の縦中横には効きません |
| 中黒 | ・ ･ · |
| 爪括弧左右 | 爪括弧 〝 〟 と引用符 “ ” ‘ ’ の**左右**位置 |
| 三点リーダ | … ⋯ ︙（二点リーダ ‥ ︰ は対象外） |

> **句読点の対象範囲**
> 「句読点」の位置補正が効くのは、禁則処理によって**行末にぶら下がった句読点だけ**です。
> 行の途中にある句読点は、補正を指定しても標準の位置のまま描かれます。
> ぶら下がりが起きるかどうかは「組版」ブロックの禁則処理の設定によります。

**中黒**は、フォントごとの差を抑えるため、「標準」で**インクの中心を本文の見た目の中心へ合わせて**描きます。
そこから上下に補正できます。

**爪括弧左右**だけは左右方向の調整で、設定は1つです。
縦書きでは、開きをセルの右上、閉じを左下へ寄せると自然に見えます。
**下補正で開きを右・閉じを左へ寄せ**、上補正では逆向きに寄せます。「標準」は中央（従来どおり）です。

## 記号の間隔と大きさ（%）

いずれも**見た目だけの調整**で、行送り・折り返し・禁則処理は変わりません。

| 項目 | 範囲 | 内容 |
|---|---|---|
| **連続記号詰め（%）** | 0〜50%（0%が従来どおり） | ダッシュ（――）、くの字点（／＼ 〳〵）、中黒（・）など、連続する記号の見た目の字間を詰めます |
| **三点リーダー点間隔（%）** | 60〜160%（100%が従来どおり） | 三点リーダー（…）の点と点、および「……」のつなぎ目の間隔。値を上げると点の間が広がります |
| **縦中横記号サイズ（%）** | 50〜150%（100%が従来どおり） | !! / !? / ！？ などの記号ペアの見た目の大きさ。数字の縦中横には効きません |
| **縦中横数字サイズ（%）** | 50〜150%（100%が従来どおり） | 12 / 2026 など、縦中横で描く2〜4桁の半角数字の見た目の大きさ。記号の縦中横には効きません |

> **三点リーダーは「連続記号詰め」の対象外です。**
> 三点リーダー（……）と二点リーダー（‥‥）はアプリ本体が点を描いており、
> 書体によらず等間隔に見えるように描きます。間隔を変えたいときは「三点リーダー点間隔」を使います。
> 下限まで詰めても、点がつながって1本の縦棒に見えることはありません。

## 波線描画・波線位置

波線系記号（～ / 〜 / 〰 / ~ など）の扱いです。

**波線描画**（描き方）

| 設定 | 動作 |
|---|---|
| 回転グリフ | フォントの質感を保って90度回転する |
| 別描画 | アプリ側で縦波線を描く |
| 自動フォールバック | 回転グリフに失敗した場合だけ別描画へ切り替える |

**波線位置**（縦位置）は、「標準」と下補正1〜6から選びます。
