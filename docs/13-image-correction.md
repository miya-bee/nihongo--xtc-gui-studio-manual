# 13. 画像・スキャンPDFの下ごしらえ

スキャンした本や資料は、文字が薄かったり背景が黄ばんでいたりすることがあります。
「濃淡補正」は、そうしたスキャンPDF/画像の薄い文字や黄ばんだ背景を、変換前に持ち上げる機能です。

![濃淡補正ダイアログ](../images/levels-correction.png)

## 使い方

「濃淡補正を有効にする」にチェックを入れてから、3つのスライダーで調整します。

- **黒点**: これより暗い値を黒に寄せます
- **白点**: これより明るい値を白に寄せます
- **ガンマ**: 黒点と白点の間の明るさを調整します

「初期値に戻す」で、黒点0・白点255・ガンマ1.0（補正なし相当）に戻せます。

## この機能と「余白トリミング」の違い

濃淡補正は明るさ・コントラストの補正です。[3章](03-typesetting.md#画像処理)で説明した
「余白トリミング」は、ページごとにインク領域を検出して余白を切り、実効文字サイズを引き上げる機能で、
役割が異なります。スキャン原稿では両方を組み合わせると効果的です。

## 白紙ページ除外

スキャン原稿や画像アーカイブには、裏写りしかない白紙ページや、章の区切りの空白ページがよく入っています。
「画像処理」の **白紙ページ除外** をONにすると、画像アーカイブとPDFから、
実質的に内容のない白紙ページを除いて変換します。無駄なページ送りが減ります。

- **既定はON** です
- 余白トリミングのON/OFFとは関係なく働きます
- [縦長分割](#縦長分割)で生じた、中身のない面にも同じ設定が効きます
- 薄い線や小さな文字があるページは残すよう、判定は控えめにしています
- 先頭が白紙のアーカイブ・PDFでは、最初に内容があるページを表紙にします
- ページ番号・進捗バーの総ページ数は、除いた白紙を差し引いた数になります

## 縦長分割

**マンガを読むための機能です。** スキャンしたマンガのページを端末の画面に
そのまま収めると、セリフが小さくて読みにくくなります。そこで縦長のページを
**端末を横に倒して読む向き**に切り分け、1ページを複数の「面」に分けて
面をめくって読む形にします。1面あたりの表示が大きくなるぶん、セリフが
読みやすくなります。

端末はページ送りしかできないため、スクロールではなくこの形にしています。
めくる回数は増えますが、文字の大きさと引き換えです。

小説などの文字ものには向きません（テキストやEPUBは対象外です）。

「画像処理」の **縦長分割** にチェックを入れ、［設定…］で中身を決めます。
**既定は無効**で、有効にしない限り変換結果はこれまでと変わりません。

![縦長分割の設定](../images/portrait-split-dialog.png)

### 設定の中身

- **分割の基準**
  - **長辺いっぱい**（既定） … 画像の幅を画面の長辺に合わせ、必要な面数を自動で決めます
  - **面数を指定** … 面数を先に決めます。2〜6面から選べます
- **のりしろ** … 面をどれだけ重ねるか。少なめ／標準（既定）／多め
- **端末の持ち方** … 右に倒す（既定）／左に倒す

設定画面には、いまの設定で何面になり、面がどれだけ重なるかが1行で出ます。
変換する前に効果を確かめられます。

### 見え方

一般的なマンガ原稿（縦横比2:3）だと、既定の「標準」で **1ページが4面**になります。
下は、同じページを分割しないで変換したものと、3面に分けたもの
（のりしろ「少なめ」に相当）です。

![分割しない場合と3面に分けた場合](../images/sample-portrait-split.png)

面をまたぐ吹き出しが1面目と2面目の両方に写っているのが「のりしろ」です。
マンガのセリフが境目で切れても読めるように、面を少し重ねてあります。

のりしろは面数で決まります。**多く重ねるほど面数が増え、めくる回数も増えます。**
一般的なマンガ原稿では次のようになります。

| のりしろ | 面数 | 面の重なり |
|---|---:|---:|
| 少なめ | 3面 | 28% |
| 標準（既定） | 4面 | 52% |
| 多め | 5面 | 64% |

**実際ののりしろは、指定より大きくなることがあります。**
面が等間隔になるように重なりを均すためで、指定値は下限として働きます。

「面数を指定」では、**4面以上なら表示の大きさは「長辺いっぱい」と同じ**で、
増えるのは面の重なりだけです。セリフを切りたくないときは面数を増やしてください。
2面・3面は、のりしろを満たすために縮小されることがあります
（一般的なマンガ原稿で2面なら長辺の62%、3面なら84%）。

### 決まりごと

- **ページ番号は、元の画像1枚を1ページとして数えます。** 面ごとには進みません。
  目次に印刷されたページ番号と突き合わせられるようにするためです
- **表紙は分割しません**。表紙ページを別に作る設定のときも、最初の（白紙でない）ページは分割せずに残します
- 分割するかどうかは、横長回転をかける**前の**向きで決めます。横長回転と同時に使っても、
  横長のページが二重に回転されることはありません
- 「白紙ページ除外」がONなら、分割で生じた中身のない面は除きます
- **横長のページは対象外**です。そちらは「横長回転」が扱います
- 縦に非常に長い画像でも **6面が上限**です。気づかないうちにページ数が跳ね上がるのを防ぎます
- 画像は長辺いっぱいには広げず、**両端に1%ずつ余白**を残します。端まで使い切ると、
  端末の縁で最外周が見えないことがあるためです
- 右ペインのプレビューも、実際の変換と同じ面数・同じページ番号で表示されます

### 対象になるファイル

画像アーカイブ（ZIP / CBZ / CBR / RAR）、PDF、単体の画像ファイル、
[フォルダの一括変換](12-folder-batch.md)。テキストやEPUBは対象外です。
