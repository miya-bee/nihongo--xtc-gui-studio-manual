# 21. Simple Reader OS（SROS）で読む

**Simple Reader OS（SROS）** は、Xteink X3・X4・X4 Pro 用の**カスタムファームウェア**です。
XTCの表示に特化しており（EPUBは扱いません）、ページを高速に表示してサクサク読めることを目指しています。
作者の E さんが note で公開しています。

- 公開記事: [Simple Reader OS Public版](https://note.com/ample_zephyr2723/n/nf7ab6e97b6b9)（2026年10月3日）
- X3/X4 用（v2.3）と X4 Pro 用（v2.3p）が別に配布されています。導入方法・フォントの置き場所などは記事と同梱の説明を見てください

Studio と SROS は、お互いの機能を意識して作られています。Studio の次の機能は **SROS 専用**です。

| Studio の機能 | 内容 | 説明している場所 |
|---|---|---|
| 出力形式 **XTCH v2**（XTC・XTCH v2 を含む） | 4階調のページを XTH2 形式（4KBごとのLZ4圧縮）で保存する | [2章](02-basic-settings.md#xtch-v2-について) |
| **LZ4圧縮** | XTC・XTCH のページをLZ4で圧縮した版を作る | [2章](02-basic-settings.md#lz4圧縮) |
| 機種 **Xteink X4 Comic／X3 Comic** | SROS の Comic Reader 用の解像度 | [下記](#comic-reader-用の機種) |
| プリセット 11〜14（**マンガ用**） | 上の3つを組み合わせた設定 | [下記](#マンガ用プリセット1114) |
| XTCツールの［LZ4圧縮して保存］ | できあがったXTC/XTCHをあとからLZ4圧縮する | [14章](14-xtc-tools.md#lz4圧縮して保存) |

> ⚠ **XTCH v2 と LZ4圧縮したファイルは、SROS でしか開けません。**
> 純正ファームウェアや、ほかのビューア・ファームウェアでは表示できません。
> SROS を使っていないときは、出力形式を **XTC** か **XTCH** にし、LZ4圧縮はオフのままにしてください（既定はオフです）。

> SROS 自体の使い方や不具合は、SROS の作者の記事を見てください。
> 公開版について作者は、版上げやサポートは期待しないでほしいと書いています。
> Studio の変換結果についての質問は、Studio 側（このマニュアルや配布元）へお願いします。

## Comic Reader 用の機種

SROS の **Comic Reader** は、マンガを高い解像度で表示する機能です。
**端末の画面のちょうど縦横2倍**の解像度で作ったファイルだけを開きます。1pxでも違うと開けません。

| 機種（Studio の表示） | 解像度 | 対象の端末 |
|---|---|---|
| **Xteink X4 Comic** | 960×1600 | X4・X4 Pro（画面はどちらも 480×800） |
| **Xteink X3 Comic** | 1056×1584 | X3（画面は 528×792） |

- 基本設定タブの「機種」で選びます。選ぶと幅・高さが自動で入ります。**Custom で寸法を打ち込むより確実**です
- 画像ZIP・CBZ・PDF などのマンガ向けです。文字の本（EPUB・TXT など）には向きません
- 「実寸」表示（[6章](06-preview.md)）では、端末で見たときと同じ大きさになるように表示します
- これらの機種で作ったXTCを Studio で開くと、自動的に Comic の機種として扱います

## マンガ用プリセット（11〜14）

プリセット一覧の11〜14番目に、SROS の Comic Reader 向けの設定が入っています（[7章](07-presets.md)）。

| プリセット | 機種 | 出力形式 | LZ4圧縮 |
|---|---|---|---|
| **X4 マンガ 4階調** | Xteink X4 Comic | XTCH v2 | ―（XTCH v2 自体が圧縮形式） |
| **X4 マンガ 2階調** | Xteink X4 Comic | XTC | オン（圧縮版のみ） |
| **X3 マンガ 4階調** | Xteink X3 Comic | XTCH v2 | ― |
| **X3 マンガ 2階調** | Xteink X3 Comic | XTC | オン（圧縮版のみ） |

4つとも共通で、白紙ページの除外と余白トリミングをオンに、ページ番号と進捗バーをオフにしています
（ページ番号などは固定の大きさで焼き込まれるので、Comic Reader の縮小表示では読めない大きさになるためです）。
ページ送り方向は右→左、ディザリングは自動判別です。

- 読み込んでから好みに合わせて変え、［既存プリセットで上書き］で自分用に保存し直せます
- 保存していない枠は、新しい版で既定値が見直されると新しい値になります
- 設定引き継ぎツールで前の版から乗り換えても、新しい版で保存済みの枠は上書きしません（[1章](01-getting-started.md#新しい版へ乗り換えるとき設定引き継ぎツール)）
- 記事URLの画面では、文字の記事向けではないので選べません

## LZ4圧縮と XTCH v2 の違い

| | XTCH v2 | LZ4圧縮 |
|---|---|---|
| 階調 | 4階調だけ（Comic の機種、または Custom で Comic の大きさのとき） | 2階調（XTC）・4階調（XTCH）どちらにも掛けられる |
| しくみ | 出力形式そのもの。4KBごとに圧縮した XTH2 で保存 | 普通に作ったXTC/XTCHを、ページごとに圧縮した版を作る。小さくならないページは圧縮しない |
| できるファイル | `本_comp_v2.xtch`（圧縮版として扱う） | 既定は圧縮版だけ（`本_comp.xtc` など）。「通常版＋圧縮版」も選べる（Comic の機種では圧縮版だけ） |
| 組み合わせ | XTCH v2 にはLZ4圧縮を重ねない。「XTC・XTCH v2」では XTC の側だけをLZ4圧縮する | ― |

どちらもファイルを小さくする仕組みで、大きなマンガを端末へ入れるときに効きます。
ファイル分割（[2章](02-basic-settings.md#ファイル分割)）の判定は、圧縮する前の大きさで行います。

## Studio で圧縮ファイルを確かめる

- 右ペインの［XTCファイルを開く］で、LZ4圧縮したXTC/XTCH・XTCH v2 も表示できます（[6章](06-preview.md)）
- XTCツールでも開けます。LZ4圧縮ページを含むファイルは読み取り専用になります（[14章](14-xtc-tools.md#読み取り専用で開くファイル)）
- バッチ実行（[20章](20-batch-mode.md)）でも、INI の設定どおりに XTCH v2・LZ4圧縮で出力できます
